# 💳 PSTU Hackathon — Digital Wallet

A modern **Digital Wallet / Mobile Financial Service** web application developed for hackathon testing and demonstration.

The project provides essential financial-service features such as money transfer, mobile recharge, bill payment, QR payment, card management, transaction history, notifications, and promotional offers.

> ⚠️ **Disclaimer:** This project is a demo application created for educational, testing, and hackathon demonstration purposes. No real banking, bKash, Nagad, or other financial service is connected.

---

## ✨ Features

### 🔐 Authentication
- User Sign In
- User Sign Up
- Forgot Password
- Profile Section

### 💸 Money & Payments
- Send Money
- Mobile Recharge
- Cash Out
- Pay Bill
- QR Payment
- E-Toll Payment
- Make Payment
- Add Money

### 💳 Card & Account Management
- Card Top-Up
- Card Management
- Request Money
- Balance Inquiry
- Mini Statement
- Transaction History

### 🔔 Additional Features
- Notification Section
- Promotional Offers
